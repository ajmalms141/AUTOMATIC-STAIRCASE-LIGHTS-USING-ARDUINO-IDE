# AUTOMATIC-STAIRCASE-LIGHTS-USING-ARDUINO-IDE
* 🚶‍♂️ Arduino-based Automatic Staircase Lighting System * 👀 Uses 2 IR sensors (first &amp; top step) * 💡 Lights turn ON when a person steps on the first step * ⬆️ Detects upward movement * 🛑 Lights turn OFF when the person reaches the top step * ⚡ Energy efficient &amp; smart automation project
